# Med Art original vector artwork

These three original abstract SVG master designs are reusable concept art for Fourthwall POD, without paid licenses or stock. This repository stores **source vector masters**; user-ready high-resolution transparent PNG exports were also produced separately in the conversation artifact pack. They are not yet uploaded to Fourthwall's media library.

- `contour-flow.svg`: for dark T-shirt blanks; confirm print dimensions and variant cost.
- `night-geometry.svg`: panoramic abstract orbits for ceramic mug wraps; confirm printed area and care specifications.
- `orbit-study.svg`: circular abstract sticker/print concept; distinct from the already created hidden `Orbit Notes` sticker.

Never represent these files as active storefront products. Artwork upload, exact catalog print zones, generated Fourthwall previews, licensing review, actual margins, refund policy, and payout setup all remain release gates.

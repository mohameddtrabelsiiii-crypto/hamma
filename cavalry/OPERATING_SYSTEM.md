# Cavalry Operating System

## Mission
Build revenue-producing digital services with $0 incremental software spend.

## Rules
- Never fabricate customers, payments, credentials, results, reviews, employers, companies, dates or numbers.
- Never bypass identity, payment, CAPTCHA, platform or account verification.
- Prefer free infrastructure and open-source tooling.
- Automate qualification, delivery, QA and reporting where technically possible.
- Escalate only when an external service requires an owner action or legally binding authorization.

## Customer acquisition
Use only legitimate public outreach and marketplaces that permit automation. Never spam or impersonate.

## Offer ladder
1. Spreadsheet/document cleanup
2. Research packs
3. Workflow automation design
4. Business-document transformation

## Delivery
Intake -> scope -> price -> payment confirmation -> process -> QA -> delivery -> request feedback -> measure conversion.
